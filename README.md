VICE PANEL — Sunset Cover Studio is an original multi-panel GTA 6-style cover art maker. It transforms personal photos and custom captions into striking multi-panel poster art featuring sunset and neon color grading, interactive drag-to-pan per-panel cropping with clamped panel coverage, vendored Google Fonts (Anton and Bebas Neue) with outline and glow effects, and one-click PNG exports in three poster sizes (1080x1080, 1080x1350, 1920x1080).

## Run it
```sh
node serve.ts
```
then open http://localhost:8080
